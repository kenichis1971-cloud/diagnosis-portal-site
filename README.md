# こころ診断ナビ

恋愛・婚活・出会い方など、自分に合う診断をやさしく選べる総合診断ポータルサイトです。

## 技術構成

- Next.js App Router
- TypeScript
- ESLint
- npm
- Vercel デプロイ想定
- Node.js 22 系以上対応

## 開発コマンド

```bash
npm install
npm run dev
npm run lint
npx tsc --noEmit
npm run build
```

## 掲載診断

- 恋愛診断（公開済み）
- 婚活診断（公開済み）
- 出会い方診断（公開済み）
- 復縁診断（準備中）
- 美容診断（準備中）
- 性の悩み診断（準備中）
