# 収益化導線の設計メモ

このメモは、今後「こころ診断ナビ」にブログ・note・STORES占い鑑定販売・ASP広告を混在させず、ページごとの役割に合わせて自然に導線を追加するための実装方針です。

> 今回は設計メモのみとし、実際の外部URL・広告リンク・広告コードは追加しません。

## 1. 現在の収益化候補

- **ブログ**
  - 記事作成済み。
  - 今後、各テーマページから自然に誘導する候補。
- **note**
  - 入口は用意済み。
  - ただし記事はまだ0本なので、現時点では準備中または控えめ導線として扱う。
- **STORES占い鑑定販売**
  - タロット占いのみ販売中。
  - 恋愛・復縁・性の悩み系ページと相性が良い。
- **ASP広告**
  - 結婚相談所、マッチング、電話占い、恋愛相談などの候補あり。
  - PR表記付きで後日追加する。

## 2. 優先順位

1. **第1優先：ブログ導線**
   - 理由：記事がすでにあり、広告感が強くなりにくい。
2. **第2優先：STORESタロット占い鑑定導線**
   - 理由：自社商品で、恋愛・復縁系との相性が良い。
3. **第3優先：ASP広告導線**
   - 理由：収益化に直結するが、PR表記と掲載位置に注意が必要。
4. **第4優先：note導線**
   - 理由：入口はあるが記事0本のため、現時点では準備中扱い。

## 4. 実装時の注意

- ASP広告を入れる場合は、広告カードやリンクの近くに必ずPR表記を入れる。
- 外部リンクには必要に応じて `target="_blank"` と `rel="noopener noreferrer"` を付ける。
- 「必ず解決」「必ず出会える」「成婚できる」などの断定表現は使わない。
- 性の悩み系ページでは露骨な表現を避ける。
- noteは記事0本のため、現時点では強く押し出さない。
- STORESタロット鑑定は、恋愛・復縁・言葉にしづらい悩みの整理として自然に紹介する。
- ブログ導線は広告感を抑えるため、最初に実装する候補として有力。

3. ASP広告枠のページ別設計
4. 実ASPリンク追加
5. note記事ができた後にnote導線追加
